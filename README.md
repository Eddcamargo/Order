# Order
WebApp para controle de produção

Criado a partir de outro projeto, incialmente apenas como exportador de pdf's, tendo o codigo aprimorado em conjunto de agentes de IA (qwen 3.5 e claude opus 5.1) 

Feito para uso em controle de produção interna, sendo executado em rede privada, para acesso de usuarios conectados via LAN
